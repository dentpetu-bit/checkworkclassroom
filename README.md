# QR Score Studio v42 — แยกนักเรียนไม่มีตัวตน

ต่อจาก v41 โดยคงระบบเดิมทั้งหมด และปรับการจัดการ “นักเรียนไม่มีตัวตน”

## เมนูจัดการนักเรียน
- แสดงเฉพาะนักเรียนปกติ
- เพิ่มปุ่ม `ไม่มีตัวตน` ที่แต่ละแถว
- เมื่อกด นักเรียนจะถูกย้ายออกจากรายชื่อปกติไปเมนู `นักเรียนไม่มีตัวตน`
- เลขที่เดิมไม่เปลี่ยนและไม่รันเลขใหม่
- ตัวอย่าง: เลขที่ 8 ถูกย้ายออก รายชื่อจะเป็น 7, 9 ต่อไปตามเลขจริง

## เมนูนักเรียนไม่มีตัวตน
- แสดงเฉพาะนักเรียนที่ตั้ง `is_nonexistent = true`
- มีปุ่ม `คืนเป็นนักเรียนปกติ`
- เมื่อคืน นักเรียนจะกลับไปในรายชื่อด้วยเลขที่เดิม
- คะแนนเดิมยังคงอยู่และกลับมาแสดงเมื่อคืนเป็นนักเรียนปกติ

## ระบบคะแนน
นักเรียนไม่มีตัวตนจะไม่ถูกนำมาใช้ใน:
- สแกนคะแนน / เครื่องยิง QR
- Manual คะแนน
- รายงานคะแนน
- คะแนนจริงและเกรด
- Template นำเข้าคะแนน
- การจับคู่ตอนนำเข้าคะแนน Excel/CSV

คะแนนเดิมของนักเรียนไม่มีตัวตน **ไม่ถูกลบจากฐานข้อมูล** เพียงถูกซ่อน/ไม่นำมาคำนวณในช่วงที่เป็น “ไม่มีตัวตน”

## Supabase
v42 ไม่ต้องรัน SQL เพิ่ม หากมีคอลัมน์ `is_nonexistent` จาก v35 อยู่แล้ว
