# QR Score Studio v40 — ตรวจงานเชื่อมเช็คชื่อแบบเลือกได้

ต่อจาก v39 โดยคงระบบเดิมทั้งหมด

## ฟังก์ชันใหม่ในหน้า “สแกนคะแนน”
เพิ่มกล่อง **เชื่อมการตรวจงานกับเช็คชื่อ**

ค่าเริ่มต้นเป็น `ไม่เชื่อม`

เมื่อครูต้องการให้การตรวจงานเป็นการเช็คเข้าเรียนด้วย:
1. เลือกช่วงคะแนน
2. เลือกห้อง
3. เลือกชิ้นงาน
4. เลือกวันที่เช็คชื่อ (ค่าเริ่มต้นเป็นวันปัจจุบัน)
5. กด `เชื่อมเช็คชื่อ`
6. เมื่อนักเรียนถูกบันทึกคะแนนสำเร็จ ระบบจะลงสถานะเวลาเรียนเป็น `มา` ให้อัตโนมัติ

## หลักป้องกันข้อมูลผิด
- การเชื่อมผูกกับ `ชิ้นงาน + ห้อง + วันที่`
- ถ้าเปลี่ยนห้อง / ช่วงคะแนน / ชิ้นงาน / วันที่ ระบบจะปิดการเชื่อมและต้องกดเชื่อมใหม่
- นักเรียน `ไม่มีตัวตน` จะไม่ถูกเช็คชื่อ
- ถ้ามีนักเรียนเป็น `มา / สาย / ลา` อยู่แล้ว ระบบจะคงสถานะเดิม ไม่เขียนทับ
- ถ้าสถานะเดิมเป็น `ขาด` ระบบจะเปลี่ยนเป็น `มา`
- ถ้ายังไม่มีข้อมูลเช็คชื่อของวันนั้น ระบบจะสร้างรายการ `มา` เฉพาะนักเรียนที่ตรวจงานแล้ว
- ใช้กับการสแกนคะแนนและ Manual ในหน้า `สแกนคะแนน`
- การนำเข้าคะแนน Excel และแก้คะแนนในหน้ารายงานไม่เชื่อมเช็คชื่อ
