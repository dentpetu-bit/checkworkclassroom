# QR Score Studio v38 — Manual Attendance Load

ปรับเฉพาะหน้าเช็คเวลาเรียนจาก v37

- เข้าเมนูเช็คเวลาเรียนแล้ว **ไม่เลือกห้อง 4/2 อัตโนมัติ**
- ไม่โหลดรายชื่อและไม่สร้างสถานะ “ขาด” อัตโนมัติ
- ครูต้องเลือกห้อง → เลือกวันที่ → กด **โหลดรายชื่อ**
- หลังจากกดโหลดรายชื่อแล้วจึงเริ่มเช็ค มา / สาย / ลา / ขาด หรือสแกน QR
- เมื่อเปลี่ยนห้องหรือวันที่ รายชื่อเดิมจะถูกซ่อน และต้องกดโหลดรายชื่อใหม่
- QR นักเรียนเช็คเองจะเปิดได้หลังโหลดรายชื่อแล้วเท่านั้น
- ปุ่มลบข้อมูลวันที่นี้, รายงาน Excel/PDF, นักเรียนไม่มีตัวตน และระบบอื่นคงเดิม
