แก้หน้าเพิ่มชิ้นงานให้แยกเป็น 2 กลุ่มชัดเจน:

- ชิ้นงานก่อนกลางภาค รันเลข 1,2,3... แยกของตัวเอง
- ชิ้นงานหลังกลางภาค รันเลข 1,2,3... แยกของตัวเอง

## v32 — ห้องเรียนยืดหยุ่น + Backup Google Drive + ล้างข้อมูล

### 1. ห้องเรียนแบบยืดหยุ่น
1. เปิด Supabase > SQL Editor
2. รันไฟล์ `schema.sql` เวอร์ชันนี้ **หนึ่งครั้ง** เพื่อสร้างตาราง `rooms`
3. เปิดหน้า `จัดการนักเรียน` จะมีส่วน `จัดการห้องเรียน`
4. สามารถเพิ่ม แก้ชื่อ และลบห้องได้ รายชื่อห้องจะเปลี่ยนในทุกเมนูทันที
5. ห้องที่ยังมีนักเรียนหรือชิ้นงานอยู่ ระบบจะไม่ยอมให้ลบเพื่อป้องกันข้อมูลเสียหาย

### 2. สำรองข้อมูลไป Google Drive
1. เปิด Google Apps Script และสร้าง Project ใหม่
2. วางไฟล์ `GoogleDriveBackup.gs` ลงใน `Code.gs`
3. Deploy > New deployment > Web app
4. Execute as: **Me** และ Who has access: **Anyone**
5. คัดลอก Web app URL
6. เปิด `config.js` แล้วใส่ URL ใน `GOOGLE_DRIVE_BACKUP_URL`
7. ที่หน้า `จัดการนักเรียน` กด `สำรองข้อมูลไป Google Drive`

Backup จะเก็บ `rooms`, `students`, `assignments`, `scores` เป็น JSON ในโฟลเดอร์ `Kru Dew QR Score Studio Backup` บน Google Drive

### 3. ล้างข้อมูลทั้งระบบ
ปุ่ม `ล้างข้อมูลทั้งระบบ` จะลบตามลำดับ `scores -> assignments -> students` แต่ **คงรายชื่อห้องไว้** และมีการยืนยัน 2 ชั้นก่อนลบ

ส่วนสูตรคะแนนจริงและฟังก์ชันอื่นทั้งหมดคงตาม v31
