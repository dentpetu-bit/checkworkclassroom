# QR Score Studio v41 — เพิ่มงานจากภาพรวม + เลือกช่วงรายงาน

ต่อจาก v40 โดยคงระบบเดิมทั้งหมด

## 1. หน้า “แสดงงานภาพรวมทุกห้อง”
ในแต่ละห้องและแต่ละช่วง:
- ก่อนกลางภาค
- กลางภาค
- หลังกลางภาค
- ปลายภาค

มีปุ่ม `+ เพิ่มชิ้นงาน` อยู่ใต้รายการงาน

เมื่อกด:
- กรอกชื่อชิ้นงาน
- กรอกคะแนนเต็ม
- กดบันทึก
- ระบบหารันลำดับงานถัดไปของห้องและช่วงนั้นให้อัตโนมัติ
- บันทึกลง Supabase และรีเฟรชภาพรวมทันที

จึงสามารถเพิ่มงานของทุกห้องได้เบ็ดเสร็จจากหน้าภาพรวม โดยไม่ต้องกลับไปหน้า “จัดการชิ้นงาน”

## 2. หน้า “รายงาน / นำเข้าคะแนน”
ด้านบนเพิ่มตัวเลือก:
- ห้องเรียน
- ก่อนกลางภาค
- กลางภาค
- หลังกลางภาค
- ปลายภาค
- ภาพรวมทั้งหมด

ขั้นตอน:
1. เลือกห้อง
2. เลือกช่วง
3. กด `แสดงข้อมูล`

ระบบจะแสดงเฉพาะช่วงที่เลือก
หากเลือก `ภาพรวมทั้งหมด` จึงแสดงครบทั้ง 4 ช่วง

เมื่อเปลี่ยนห้องหรือเปลี่ยนช่วง รายงานเดิมจะถูกซ่อนจนกว่าจะกด `แสดงข้อมูล` ใหม่ เพื่อป้องกันการดูข้อมูลผิดห้องหรือผิดช่วง

ส่วนระบบนำเข้าคะแนน, Export Excel/PNG, แก้คะแนนในตาราง และระบบอื่นยังคงเดิม
