# QR Score Studio v18 — Split Assignment Manager

แก้หน้าเพิ่มชิ้นงานให้แยกเป็น 2 กลุ่มชัดเจน:

- ชิ้นงานก่อนกลางภาค รันเลข 1,2,3... แยกของตัวเอง
- ชิ้นงานหลังกลางภาค รันเลข 1,2,3... แยกของตัวเอง
- ปุ่มเลื่อนขึ้น/ลง เลื่อนเฉพาะงานในช่วงเดียวกัน
- หน้ารายงานยังดึงไปแสดงแยกก่อนกลางภาค/หลังกลางภาคเหมือนเดิม
