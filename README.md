# QR Score Studio v18 — Split Assignment Manager

แก้หน้าเพิ่มชิ้นงานให้แยกเป็น 2 กลุ่มชัดเจน:

- ชิ้นงานก่อนกลางภาค รันเลข 1,2,3... แยกของตัวเอง
- ชิ้นงานหลังกลางภาค รันเลข 1,2,3... แยกของตัวเอง
- ปุ่มเลื่อนขึ้น/ลง เลื่อนเฉพาะงานในช่วงเดียวกัน
- หน้ารายงานยังดึงไปแสดงแยกก่อนกลางภาค/หลังกลางภาคเหมือนเดิม

วิธีอัปเดต: อัปโหลดไฟล์ทั้งหมดทับของเดิม แล้วเปิด `?v=18` หรือกด Ctrl + Shift + R


## v19 — แยกช่วงในหน้าสแกนคะแนน
- เพิ่มปุ่มเลือก **ก่อนกลางภาค / หลังกลางภาค** ก่อนเลือกห้องและชิ้นงาน
- ช่องชิ้นงานจะแสดงเฉพาะงานของช่วงที่เลือก
- ใช้ข้อมูล `period` เดิม ไม่ต้องแก้ฐานข้อมูลหรือ schema
- หากเปลี่ยนช่วงหลังสแกนนักเรียนแล้ว ระบบจะยกเลิกรอบนั้นและให้สแกนนักเรียนใหม่เพื่อป้องกันลงคะแนนผิดช่วง

วิธีอัปเดต: อัปโหลดไฟล์ทั้งหมดทับของเดิม แล้วเปิด `?v=19` หรือกด Ctrl + Shift + R


## v24 Original — แบ่งชิ้นงาน 4 ช่วง
- คงหน้าตาและธีม Original เดิม
- แบ่งชิ้นงาน: ก่อนกลางภาค / กลางภาค / หลังกลางภาค / ปลายภาค
- หน้า "คะแนนจริง" ดึงชิ้นงานตาม 4 ช่วงโดยตรง
- คงการแก้ Excel คะแนนจริงจาก v21
- ไม่แก้ธีม สี ตาราง ปุ่ม หรือรูปแบบตกแต่งส่วนอื่น


## v25 — เลือกงานล่าสุดอัตโนมัติในหน้าสแกนคะแนน
- เมื่อเลือกห้อง ระบบโหลดชิ้นงานของห้องนั้น
- ระบบเลือกชิ้นงานล่าสุดของช่วงคะแนนที่กำลังเลือกให้อัตโนมัติ
- เมื่อเปลี่ยนช่วงคะแนน ระบบเลือกงานล่าสุดของช่วงนั้นให้อัตโนมัติ
- คงธีม Original และระบบแบ่งชิ้นงาน 4 ช่วงจาก v24


## v26 — หน้าแสกนคะแนน 4 ช่วง
- เพิ่มปุ่ม ก่อนกลางภาค / กลางภาค / หลังกลางภาค / ปลายภาค
- เมื่อเลือกช่วง ระบบแสดงเฉพาะชิ้นงานของช่วงนั้น
- ระบบยังเลือกงานล่าสุดของห้องและช่วงนั้นให้อัตโนมัติ
- คงธีม Original เดิม


## v27 — หน้ารายงานแสดงครบ 4 ช่วง
