# QR Score Studio v39 — แสดงงานภาพรวมทุกห้อง

เพิ่มเมนูใหม่ **แสดงงานภาพรวมทุกห้อง** ต่อจาก v38 โดยไม่เปลี่ยนระบบเดิม

- แต่ละห้องแสดงเป็นคอลัมน์เรียงจากซ้ายไปขวา
- เลื่อนแนวนอนไปทางขวาเพื่อดูห้องถัดไป
- แสดงครบทุกห้องในระบบ แม้ห้องนั้นยังไม่มีชิ้นงาน
- ภายในแต่ละห้องแยกเป็น 4 ช่วง: ก่อนกลางภาค / กลางภาค / หลังกลางภาค / ปลายภาค
- แต่ละงานแสดงลำดับ ชื่องาน และคะแนนเต็ม
- แต่ละช่วงแสดงจำนวนงานและคะแนนเต็มรวม
- แต่ละห้องแสดงจำนวนงานและคะแนนเต็มรวม
- ด้านบนมีสรุปจำนวนห้อง ห้องที่มีงาน งานทั้งหมด และคะแนนเต็มรวม
- มีปุ่ม **แสดง / รีเฟรชภาพรวม**
- เมื่อเปิดเมนู ระบบโหลดข้อมูลล่าสุดจาก Supabase ให้อัตโนมัติ

## Supabase
v39 ไม่ต้องรัน SQL เพิ่ม หากเคยรัน schema ของ v35 แล้ว
