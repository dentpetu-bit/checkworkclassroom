# QR Score Studio by Kru Dew — v17 Stable Split Report

เพิ่มหน้า รายงานคะแนน แยกเป็น 2 ตารางทันที:
- คะแนนก่อนกลางภาค
- คะแนนหลังกลางภาค

แต่ละตารางมีปุ่ม Export แยกกัน:
- Excel ก่อนกลางภาค
- PNG ก่อนกลางภาค
- Excel หลังกลางภาค
- PNG หลังกลางภาค

ยังคงฟีเจอร์เดิมจาก v16: คะแนนจริง, แบ่งชิ้นงานก่อน/หลังกลางภาค, เครื่องยิงบาร์โค้ด/QR, แจ้งเตือนคะแนนซ้ำ, ช่อง 0 สีแดง, คะแนนเต็มสีเขียว

วิธีใช้:
1. อัปโหลดไฟล์ทั้งหมดทับของเดิม
2. เปิด `?v=17` หรือกด Ctrl + Shift + R
3. ถ้ายังไม่เคยรัน v16 ให้รัน `schema.sql` ใน Supabase ก่อน
